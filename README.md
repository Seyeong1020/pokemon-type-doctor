# 포켓몬상성박사

Next.js로 만든 포켓몬 타입 상성 훈련 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 현재 범위

- 첫 화면
- 포켓몬 타입 상성 퀴즈
- 18개 타입 버튼
- 정답 확인 후 배율 설명
- 간단한 상성 공부 화면

## 배포

Vercel에서 이 저장소를 연결하면 Next.js 프로젝트로 자동 인식됩니다.
